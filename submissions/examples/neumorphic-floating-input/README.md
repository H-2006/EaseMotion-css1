# Interactive Floating Input Field with Neumorphism Styling

An interactive floating label input field component styled using soft neumorphic light and shadow design techniques and pure CSS.

## Features
- **Zero JS Dependencies**: Label float logic works via standard CSS `:placeholder-shown` and `:focus` pseudo-classes.
- **Neumorphic Aesthetic**: Dual soft highlights and inset drop-shadows mimicking realistic light sources.
- **EaseMotion Integration**: Built using EaseMotion transition tokens (`--easemotion-transition-base`, `--easemotion-transition-fast`).
- **Accessibility Ready**: Fully compliant with `prefers-reduced-motion: reduce`.
- **Responsive**: Flexible scaling up to `380px` max-width across mobile, tablet, and desktop viewports.

## Usage
Include `style.css` in your document and wrap the input and label elements inside `.neu-input-wrapper`.
